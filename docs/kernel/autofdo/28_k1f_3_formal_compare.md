# K1f-3 K-BASE 与 K-AFDO 正式比较

正式比较完成 **10/10** 个 block，机制计数完成 **5/5** 个 block。正式比较以 pipe 为主指标。 [证据索引](evidence/28-k1f-3/index.json) · [结构化结果与逐轮记录](evidence/28-k1f-3/run-summary.json)

## 开工、预登记与首启

PLAT 在 `schedutil` 下五分钟采了 31 点，最小／中位／最高为 **52.582 °C / 53.556 °C / 54.043 °C**。开工阈值为五分钟中位 ≤58 °C。

锁定收据 SHA-256 为 `734cc949810798dcbaf1e87a4ae83c3f3645d255f204ebf748b9c1fdbf9ed84b`，N=10。A 为 K-BASE，B 为 K-AFDO。种子 20261125 的正式顺序为 `AB BA BA AB BA AB AB BA BA AB`。机制对照也使用该种子独立锁定 5 组，顺序为 `BA BA AB AB AB`。预登记 SHA-256 为 `ce736bed01f347e62ff01af6d8ef487c7f4d4ed74bfea4e6beb43ab151051c8b`。 [K1f-2 N 锁定与布局对照](27_k1f_2_resume_aa_layout.md)

boot_a 替换实验用 `zImage-kbase-s2`，新增 `zImage-kafdo`，读回 SHA-256 `a663e13858334ae9bf8de1404d4965ab13856f60ee868393177a988e94eba795`。413 个原文件逐一核对 SHA 均一致，预计最低空闲 1,372,160 B，读回空闲 1,374,208 B。

K-AFDO build-id `43ba5d455daec5da17e7521048767cdace012c91`，60.863 秒取得首条身份响应。ARM32、直启、cmdline、规范化 FDT、10/10 模块、dmesg、HDMI、网络、dlog、D-Bus 均通过。安静门禁用时 30.35 秒，放行温度 53.556 °C。PMU 冒烟计数为 `cycles:k` 2,996,520,912, `cycles:u` 49,569,989, `instructions:k` 880,726,484。pipe、mmfault、forkexec 三项都完成，耗时分别为 12.303、9.732、15.138 秒。
