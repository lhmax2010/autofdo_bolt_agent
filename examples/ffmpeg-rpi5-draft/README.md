# FFmpeg on RPi5 draft example

This example was generated by `init` and `run --dry-run` with the three
SHA-checked experiment clips. [job.json](job.json) shows the draft, and
[dry-run.json](dry-run.json) shows the nine planned stages. The paths use
`${WORKDIR}` and `${MEDIA_DIR}` as placeholders. These files are for inspection.
Use the [skill](../../skills/afdo-workflow/SKILL.md) to generate a fresh draft
for your host. The example is not a runnable job.
