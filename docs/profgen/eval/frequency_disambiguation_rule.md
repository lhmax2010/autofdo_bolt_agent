1. 固件降频确认：任一运行期间任一可用固件来源显示降频、欠压或频率上限标志（当前位或自本次开机以来的累计位），或固件报告的 ARM 实际时钟 < 1.455GHz，或四核对照中逐秒 cycles/task-clock < 1.455GHz 连续 ≥3 秒：判为“固件层面真实降频”，停止并报告，后续性能测量待用户处理硬件后进行。
2. 计数口径差异：至少一种固件来源可用且全程无任何标志，单核与四核对照逐秒 cycles/task-clock 全部 ≥1.455GHz，且对照最高温度不低于 FFmpeg 运行最高温度，而 FFmpeg 逐秒总 cycles/task-clock 仍 <1.455GHz：判为“PMU/计时口径差异（非降频）”，停止并报告。不生成任何修订，新判据由用户决定。
3. 其余情况（固件来源全部不可用、结果混合）判为 unknown，停止并报告。
