    [llvm-profgen] Add IP sample reader and dsoff address conversion
    
    Add an explicitly gated IPPerfReader for fixed perf-script IP fields.
    Preserve mapping identity records, filter events, PIDs and raw DSO paths,
    and convert file offsets through unique executable ELF PT_LOAD segments.
    Keep checked uint64 sample counts and period sums by ELF virtual address.
    
    Reject incompatible options and unadmitted perf.data input in IP mode.
    Expose hidden deterministic counters for reader tests. Until profile
    construction lands, return a fixed error without opening the output.
    Leave the existing LBR reader and profile generation behavior unchanged.
    
    Add reader, address, option, malformed-input and output-preservation lit
    coverage using the IP-mode inputs. Existing 50 lit results are unchanged;
    all seven new tests pass and the frozen C1 matrix has zero differences.
