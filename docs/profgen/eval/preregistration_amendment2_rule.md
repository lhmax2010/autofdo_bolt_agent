# 预注册修订2的判定规则（诊断采集前登记）

以下为用户上一任务第一节第4条原文。此文件登记判定规则，不代表已生成修订2；原预注册与修订1保持不变，判定不使用任何配置间比较结果。

4. 预先确定的判定规则（采集诊断数据前，把本节第 4 条原文提交为 docs/profgen/eval/preregistration_amendment2_rule.md 并推送）：
   - 若全部运行前后的每 CPU 校准频率均 ≥ 固定频率的 97%，且全部 FFmpeg 诊断运行（a 与 b）的用户态有效频率 ≥ 97%：判为测量口径问题（非降频）。生成修订 2：节流判据改为"运行前后绑核校准频率 ≥ 97% 且逐秒 scaling_cur_freq 全程等于固定值且温度低于原阈值"，用户态有效频率作为辅助记录；其余不变。第一轮数据没有绑核校准，对其按"用户态有效频率 ≥ 97%（若可由已存数据算出）且其余条件满足"判定，算不出的保持 unknown；剔除前后两套并列。同时在报告中说明总体有效频率偏低的来源（内核时间、缺页、回收活动），并评估其对后续性能测量的影响。
   - 若任一次校准频率 < 97%，或任一 FFmpeg 诊断运行的用户态有效频率 < 97%：判为疑似真实降频，不生成修订 2，停下报告，附逐秒数据；后续性能测量须待用户处理后再进行。
   - 判定只看诊断数据，不看任何配置间结果。
